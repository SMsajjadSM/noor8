## ۲. دستی با GitHub واقعی (یک‌بار، روی Deploy آزمایشی)

1. ورود با رمز اشتباه رد می‌شود؛ با رمز درست وارد می‌شوید. بعد از خروج، `/admin/dashboard` به login می‌رود.
2. در پنل یک محصول بسازید. در GitHub: Branch `content-drafts` ساخته شده، فایل جدید در `data/products/` هست، **`main` تغییری نکرده** و Vercel Deploy جدیدی نساخته.
3. صفحه «انتشار» ← آن محصول را فقط انتخاب و منتشر کنید. در GitHub یک Commit روی `main` می‌بینید؛ Vercel Deploy می‌سازد؛ وضعیت در پنل از «در صف» به «موفق» می‌رسد.
4. بعد از Deploy محصول در `/products` و `/sitemap.xml` هست. دوباره انتشار همان مورد: «تغییری برای انتشار نیست».
5. تصویر آپلود کنید؛ در محصول/مقاله استفاده کنید؛ تلاش برای حذف آن در رسانه رد می‌شود.
6. وضعیت پیش‌نویس: محصول را «پیش‌نویس» کنید و منتشر کنید؛ از سایت عمومی ناپدید می‌شود.
7. دو تب باز کنید، یک محصول را در هر دو ویرایش و ذخیره کنید؛ دومی پیام تعارض می‌گیرد.
8. توکن را عمداً غلط کنید: پنل پیام خطای قابل‌فهم نشان می‌دهد، نه خطای خام.
